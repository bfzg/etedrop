# 分享接口说明

## 一、背景与目标

FastSend 分享功能当前包含两部分：**REST API**（创建/查询/列表/删除分享记录，服务端内存存储）与 **WebSocket 设备通道**（`/api/share`，用于 Desktop 设备注册与后续浏览器连接设备）。本文档约定 REST 的路径、请求响应格式与错误处理；WS 行为以《信令协议说明》为准，此处仅说明与分享流程的关系。

---

## 二、范围

| In Scope | Out of Scope |
|----------|--------------|
| 分享 REST API：路径、方法、请求/响应、错误码 | WebSocket 消息细节（见《信令协议说明》） |
| 当前实现：服务端内存存储 | 未来「分享仅存 Desktop」方案下的 API 调整 |
| 鉴权要求（当前无，预留说明） | P2P DataChannel 内业务协议 |

---

## 三、设计方案

- **当前实现**：客户端（如 Flutter/Desktop）调用服务端 REST 创建/查询/删除分享；服务端用内存 `Map` 存储，key 为规范化后的分享码（大写 trim）。
- **与方案文档的关系**：《WebRTC网盘与分享方案》§8 中「分享记录存 Desktop、服务端无状态」为可选方案；当前服务端仍提供 REST 存储，便于先跑通流程，后续可收敛为「仅设备通道 + 分享页」。
- **分享页**：计划中提供 `GET /share/:deviceId/:shareCode` 类页面，由前端或静态模板渲染，本文档不定义该页面的接口格式，仅注明存在该需求。

---

## 四、接口定义

### 4.1 基础信息

- **Base URL**：由部署决定，例如 `http://localhost:3000` 或 `https://api.example.com`。
- **Content-Type**：请求/响应均为 `application/json`（除未来可能的分享页 HTML）。
- **鉴权**：当前无；后续若增加鉴权，将在请求头或 Query 中约定（如 `Authorization: Bearer <token>`）。

---

### 4.2 创建分享

**POST** `/api/share`

**请求体**（JSON）：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| path | string | 是 | 文件相对路径（业务含义，服务端不校验文件存在） |
| fileName | string | 是 | 文件名 |
| size | number | 是 | 文件大小（字节） |
| password | string | 否 | 访问密码，服务端存 SHA256 哈希 |
| expiresIn | number | 否 | 有效时长（毫秒），相对当前时间；不传则不过期 |

**响应**（200）：JSON

| 字段 | 类型 | 说明 |
|------|------|------|
| code | string | 分享码（8 位十六进制大写） |
| path | string | 同请求 |
| fileName | string | 同请求 |
| size | number | 同请求 |
| hasPassword | boolean | 是否设置了密码 |
| createdAt | number | 创建时间戳（毫秒） |
| expiresAt | number \| undefined | 过期时间戳；未设置则无此字段 |

**示例**：

```json
// 请求
{ "path": "docs/a.pdf", "fileName": "a.pdf", "size": 1024000, "password": "123", "expiresIn": 86400000 }

// 响应
{ "code": "A1B2C3D4", "path": "docs/a.pdf", "fileName": "a.pdf", "size": 1024000, "hasPassword": true, "createdAt": 1709900000000, "expiresAt": 1709986400000 }
```

---

### 4.3 分享列表

**GET** `/api/share`

**请求**：无 Query 要求。

**响应**（200）：JSON 数组，元素同「创建分享」响应；按 `createdAt` 倒序。已过期记录会在本次列表中清理后返回。

---

### 4.4 按码查询分享

**GET** `/api/share/:code`

**Query**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| password | string | 有密码时必填 | 访问密码 |

**响应**：

- 成功（200）：同「创建分享」响应中的单条结构。
- 不存在/已过期/密码错误：**404**，Body 为 Nest 默认错误结构（如 `{ "statusCode": 404, "message": "分享不存在或已过期" }`）。

**说明**：code 在服务端会做 `trim().toUpperCase()` 规范化。

---

### 4.5 删除分享

**DELETE** `/api/share/:code`

**响应**（200）：JSON

| 字段 | 类型 | 说明 |
|------|------|------|
| success | boolean | 是否删除成功（未找到视为 false） |

**说明**：code 同样做规范化；不存在时返回 `{ "success": false }`，不返回 404。

---

## 五、异常与边界处理

- **400/校验错误**：若未来对 DTO 增加 class-validator，缺少必填或类型错误可返回 400，格式以 Nest 默认为准。
- **404**：仅「按码查询」在不存在/过期/密码错误时返回 404，消息统一为「分享不存在或已过期」。
- **500**：未捕获异常由 Nest 统一处理，建议在生产环境隐藏堆栈。

---

## 六、验收标准

- 能根据本文档用 Postman/curl 完成创建、列表、按码查询（含密码）、删除，且响应字段与示例一致。
- 过期分享在查询时返回 404，在列表中不再出现（且被清理）。
- 文档与《信令协议说明》中「分享/设备通道」无冲突；后续若增加分享页或鉴权，在本文档中补充章节即可。

---

## 七、待办项与风险

| 待办 | 说明 |
|------|------|
| 分享页 | 定义并实现 `GET /share/:deviceId/:shareCode` 类页面（或 SPA 路由），与 WS 设备通道配合 |
| 鉴权 | 若为 REST 增加鉴权，需在本文档补充 Header/Query 约定及 401 响应格式 |
| 与方案文档对齐 | 若最终采用「分享仅存 Desktop」，需将本 REST 收敛或改为「仅服务端查询接口」并更新文档 |

**风险**：当前分享码为服务端生成、全局唯一（内存 Map），多实例部署时需考虑共享存储或单点，否则会冲突或不一致。
