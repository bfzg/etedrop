# Flutter 客户端功能与开发任务

> 依据《WebRTC网盘与分享方案》§8、《信令协议说明》、《Flutter与服务端联调计划》及当前 fast_send_flutter 实现整理。用于对齐产品能力、页面与开发任务。

---

## 一、产品角色与目标

- **Flutter 客户端**：桌面/移动端应用，作为「本机」角色，可：
  - **传文件**：生成取件码或输入取件码，通过 WebRTC 与对端直连收发文件。
  - **网盘**：选择本地存储目录，浏览、上传、新建文件夹、删除；对文件创建分享，生成分享码与分享链接。
  - **设备**：以设备身份连接服务端（device-online、心跳），便于他人通过分享链接连到本机取文件。
- **分享链接**：格式为 `{shareLinkBaseUrl}/share/{deviceId}/{shareCode}`，由服务端提供分享页；用户打开链接后在浏览器中连设备、走 WebRTC 下载（当前分享页仅做「设备在线/离线」展示，下载流程在 P2P 侧扩展）。

## 三、页面与路由

| 路由 | 页面 | 说明 |
|------|------|------|
| `/`（或默认） | 主导航壳 | 底部/侧边导航，子路由为 cloud / send / receive / settings |
| `/cloud` | 网盘页 | 面包屑、文件列表/表格、上传/新建/删除、分享入口 |
| `/send` | 发送页 | 取件码展示、等待接收方、WebRTC 发送 |
| `/receive` | 接收页 | 取件码输入、连接发送方、WebRTC 接收 |
| `/settings` | 设置页 | 设备 ID、设备名、存储目录等 |

## 四、开发任务列表

### 4.1 已完成

- [x] 分享创建后展示**分享码**与**分享链接**（分享链接依赖设备已连接，否则提示先连接）。
- [x] **分享链接基地址**可配置：`AppConstants.shareLinkBaseUrl`，默认 `http://localhost:3000`（与服务端同地址），便于本地联调与后续改为配置文件。
- [x] 网盘：存储目录、列表、上传、新建文件夹、删除、创建分享入口。
- [x] 传文件：发送/接收页与取件码流程。
- [x] 设备：连接服务端、device-online、心跳、设备信息展示。
- [x] **设备自动连接**：应用启动时自动连接信令服务器（`deviceAutoConnectProvider`）。
- [x] **连接状态三态展示**：设置页展示连接中（蓝色 + 转圈）、已连接（绿色）、连接失败（灰色 + 红色错误文案 + 重连按钮）。
- [x] **分享自动复制链接**：创建分享后自动复制分享链接到剪贴板并提示。
- [x] **响应式布局**：`AdaptiveLayout` + `breakpoints.dart`，桌面/移动端自适应。
- [x] **紧凑 AppBar**：AppBar 高度缩减至 36px，面包屑左侧 + 操作按钮右侧。
- [x] **移除全局 DraggableTopBar**：桌面端通过侧边栏拖拽窗口，macOS 侧边栏顶部安全距离。

### 4.2 建议优先（与分享/联调相关）

- [ ] **我的分享页**：展示当前设备已创建分享列表（调用 shareListProvider），每项展示文件名、分享码、分享链接（可复制）、过期时间、删除按钮；无设备连接时分享链接可灰显或提示「连接后可见」。
- [ ] **分享链接配置**：将 `shareLinkBaseUrl` 从常量改为可配置（如设置页输入、或从配置文件/环境读取），便于部署时改为正式域名。
- [ ] **联调**：与服务端对齐 baseUrl、WS 地址（`/api/connect`、`/api/share`）、错误码（如 OFFLINE、SESSION_TIMEOUT），按《Flutter与服务端联调计划》做一次端到端联调（取件码、设备上线、分享页打开链接）。

### 4.3 后续增强（按产品节奏）

- [ ] **分享页 P2P 下载**：浏览器打开分享链接后，除「设备在线/离线」外，可请求文件信息、输入密码、通过 WebRTC DataChannel 从 Flutter 端（设备）拉取文件；Flutter 端需响应 P2P 协议（如 share-request、share-verify、download-start、file-chunk）。
- [ ] **多语言**：已有 l10n 骨架，补全分享、网盘、设置等文案。
- [ ] **错误与重连**：WS 断线重连、错误码统一展示（如「设备离线」「会话超时」）。
- [ ] **桌面端**：托盘、开机自启等（若目标平台包含桌面）。

## 五、配置项汇总（便于后续改为配置文件）

| 配置项 | 当前位置 | 说明 | 建议默认 |
|--------|----------|------|----------|
| 信令地址 | `AppConstants.signalingServerUrl` | 取件码传文件 WS | `wss://...` 或 `ws://localhost:3000/api/connect` |
| 设备/分享 WS | `AppConstants.shareServerUrl` | 设备上线、分享通道 | `ws://localhost:3000/api/share` |
| 分享链接基地址 | `AppConstants.shareLinkBaseUrl` | 生成分享链接前缀 | `http://localhost:3000` |
| 心跳间隔 | `AppConstants.heartbeatInterval` | 设备心跳（毫秒） | 30000 |
| 重连间隔 | `AppConstants.reconnectInterval` | WS 重连（毫秒） | 5000 |

后续可将上述项放入 assets 配置文件或设置页，便于不同环境切换。
