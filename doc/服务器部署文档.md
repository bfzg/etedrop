# Ubuntu 部署配置（Nginx + HTTPS + fast_send_server + 官网）

约定：**后端** `127.0.0.1:40321`，**静态站** `/home/app/www.etedrop.com`，**Nginx 站点文件** `/etc/nginx/sites-enabled/api`。海外用 **`doc/nginx-etedrop.conf.example`**；国内只跑 **api-cn + cn** 时用 **`doc/nginx-etedrop-cn.conf.example`**（勿整份照搬海外示例，否则会引用不存在的 `api.etedrop.com` 证书）。

---

## 1. DNS（Cloudflare 等）

| 记录 | 类型 | 指向 |
|------|------|------|
| `api.etedrop.com` | A | 海外服务器公网 IP |
| `api-cn.etedrop.com` | A | 国内服务器公网 IP |
| `etedrop.com` / `www.etedrop.com` | A | 海外或按需 |
| `cn.etedrop.com`（可选） | A | 国内服务器公网 IP |

证书申请期间：经 Cloudflare 解析的对应主机名设为 **DNS only（灰云）**。证书就绪后：**Proxied**，**SSL/TLS → Full (strict)**。

## 2. Node 与后端

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
. "$HOME/.nvm/nvm.sh"
nvm install 24

npm ci
npm run build
npm install -g pm2
PORT=40321 pm2 start dist/main.js --name etedrop-server
pm2 save && pm2 startup
```

```bash
pm2 stop etedrop-server
pm2 restart etedrop-server
pm2 logs etedrop-server
```

## 3. 官网静态文件

```bash
sudo mkdir -p /home/app/www.etedrop.com
sudo chown -R www-data:www-data /home/app/www.etedrop.com
sudo chmod o+x /home /home/app
```

本机构建产物同步（路径按你 Docusaurus 输出改）：

```bash
rsync -av --delete ./website/build/ user@服务器:/home/app/www.etedrop.com/
```

国内镜像站构建（可选）：

```bash
CHINA_MIRROR_ORIGIN=https://cn.etedrop.com npm run build
```

## 4. Nginx

```bash
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
sudo rm -f /etc/nginx/sites-enabled/default
sudo rm -f /etc/nginx/sites-enabled/api
```

海外机：

```bash
sudo cp /path/to/repo/doc/nginx-etedrop.conf.example /etc/nginx/sites-enabled/api
```

国内机（仅 **api-cn** + **cn**）：

```bash
sudo cp /path/to/repo/doc/nginx-etedrop-cn.conf.example /etc/nginx/sites-enabled/api
```

```bash
sudo nano /etc/nginx/sites-enabled/api
sudo nginx -t && sudo systemctl reload nginx
```

直接编辑 **`/etc/nginx/sites-enabled/api`**（普通文件，非软链）。

`api` 内按需改：`root`、`ssl_certificate` / `ssl_certificate_key`；**`http {}` 里 `map $http_upgrade $connection_upgrade` 全局只保留一份**；证书未下发前注释掉对应 **`listen 443`** 整段 `server`。

## 5. Certbot

```bash
sudo apt install -y certbot python3-certbot-nginx
```

海外机：

```bash
sudo certbot certonly --webroot -w /var/www/html -d etedrop.com -d www.etedrop.com
sudo certbot certonly --webroot -w /var/www/html -d api.etedrop.com
```

国内机（官网走 **`cn.etedrop.com`**，API 走 **`api-cn.etedrop.com`**）：

```bash
sudo certbot certonly --webroot -w /var/www/html -d cn.etedrop.com
sudo certbot certonly --webroot -w /var/www/html -d api-cn.etedrop.com
```

```bash
sudo certbot certificates
systemctl list-timers | grep certbot
sudo certbot renew --dry-run
```

Nginx 里 `ssl_certificate` 等与 `certbot certificates` 一致；国内官网 `server_name` / 证书用 **`cn.etedrop.com`**（`/etc/letsencrypt/live/cn.etedrop.com/`），不要照抄海外机上的 `etedrop.com` / `www`。
