# Ubuntu 部署配置（Nginx + HTTPS + fast_send_server + 官网）

## 架构说明（双机 + 客户端选线）

应用内 API / WebSocket 线路由 **`fast_send_flutter/lib/core/config/server_endpoints.dart`** 解析：

| 线路 | 默认 HTTPS API | 典型 Nginx 示例 |
|------|----------------|-----------------|
| 全球 | `https://api.etedrop.com` | `doc/nginx-etedrop.conf.example`（海外机） |
| 大陆 | `https://api.etedrop.cn` | `doc/nginx-etedrop-cn.conf.example`（国内机） |

两台服务器**各自**反代本机 `127.0.0.1:40321` 即可，**不再需要在海外机上同时提供 `api-cn.etedrop.com`**。旧版曾把 `api-cn.etedrop.com` 与全球 API 同机部署以做 DNS 分流；当前推荐 **`api.etedrop.cn` 只解析到国内机**。

约定：

- **后端**：`127.0.0.1:40321`（`fast_send_server`）
- **Nginx 站点文件**：可命名为 `/etc/nginx/sites-enabled/etedrop`（或沿用你已有的 `api` 等文件名）
- **静态站目录**（仅服务器本地路径名，可自定义）  
  - 国际站 build：`/home/app/www.etedrop.com/`  
  - 国内站 `build:domestic`：`/home/app/www.etedrop.cn/`

## 1. DNS

### 全球机（国际站）

| 记录 | 类型 | 指向 |
|------|------|------|
| `api.etedrop.com` | A / AAAA | **海外**服务器公网 IP |
| `etedrop.com` / `www.etedrop.com` | A / AAAA | 海外或 CDN（与证书一致即可） |

### 国内机（独立域名 etedrop.cn）

| 记录 | 类型 | 指向 |
|------|------|------|
| `api.etedrop.cn` | A / AAAA | **国内**服务器公网 IP |
| `etedrop.cn` / `www.etedrop.cn` | A / AAAA | **国内**服务器公网 IP |
| `*.etedrop.cn` | 可选 | 仅当你需要子域与官网同机、且已配置**通配符证书**时 |

> 历史说明：旧版曾使用 `api-cn.etedrop.com` 等；现以 **`api.etedrop.com` + `api.etedrop.cn` 分属两台** 为准。

证书申请期间：经 Cloudflare 等代理时，将对应主机名设为 **DNS only（灰云）**；证书就绪后按需改为 **Proxied** 并设 **SSL/TLS → Full (strict)**（按你的策略调整）。

## 2. Node 与后端

在**各自服务器**上安装 Node、构建并运行（路径以仓库 `fast_send_server` 为准）：

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.4/install.sh | bash
. "$HOME/.nvm/nvm.sh"
nvm install 24

npm ci
npm run build
npm install -g pm2
PORT=40321 pm2 start dist/main.js --name etedrop-server
pm2 save && pm2 startup
```

```bash
pm2 stop etedrop-server
pm2 restart etedrop-server
pm2 logs etedrop-server
```

## 3. 官网静态文件

**国际站**（英文等多语言，默认 `npm run build` 产物）：

```bash
sudo mkdir -p /home/app/www.etedrop.com
sudo chown -R www-data:www-data /home/app/www.etedrop.com
sudo chmod o+x /home /home/app
```

```bash
rsync -av --delete ./website/build/ user@海外机:/home/app/www.etedrop.com/
```

**国内站**（`npm run build:domestic`，根路径/备案等见 `website` 与 `docusaurus.config.ts`）：

```bash
sudo mkdir -p /home/app/www.etedrop.cn
sudo chown -R www-data:www-data /home/app/www.etedrop.cn
sudo chmod o+x /home /home/app
```

```bash
# 在 website 目录
npm run build:domestic
rsync -av --delete ./build/ user@国内机:/home/app/www.etedrop.cn/
```

国际站构建若需写死国内镜像根地址（如横幅跳转），可：

```bash
CHINA_MIRROR_ORIGIN=https://etedrop.cn npm run build
```

## 4. Nginx

```bash
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
sudo rm -f /etc/nginx/sites-enabled/default
# 若已有旧配置且需替换，先备份再删
# sudo rm -f /etc/nginx/sites-enabled/api
```

**全球机**（只含 `api.etedrop.com` + `etedrop.com` 官网，**不含** `api.etedrop.cn` / `api-cn`）：

```bash
sudo cp /path/to/repo/doc/nginx-etedrop.conf.example /etc/nginx/sites-available/etedrop
sudo ln -sf /etc/nginx/sites-available/etedrop /etc/nginx/sites-enabled/etedrop
```

**国内机**（`api.etedrop.cn` + `etedrop.cn` / `www` 重定向；泛域名见示例文件末注释段）：

```bash
sudo cp /path/to/repo/doc/nginx-etedrop-cn.conf.example /etc/nginx/sites-available/etedrop
sudo ln -sf /etc/nginx/sites-available/etedrop /etc/nginx/sites-enabled/etedrop
```

```bash
sudo nano /etc/nginx/sites-available/etedrop
sudo nginx -t && sudo systemctl reload nginx
```

注意：

- 编辑 **`sites-available/`** 下源文件；若使用软链，勿直接改 `sites-enabled` 里链到的目标以外的文件，避免与 Vim E166 等问题混淆。
- **`http {}` 中 `map $http_upgrade $connection_upgrade` 全局只保留一份**。
- 证书未下发前，注释掉对应 **`listen 443` 的整段** `server {}`，只保留 80 与 ACME。
- 按实际修改 `root`、`ssl_certificate` / `ssl_certificate_key`。
- **国内**通配 `*.etedrop.cn` 需**通配符证书**；默认示例仅 `etedrop.cn` + `www.etedrop.cn`，与 `certbot -d etedrop.cn -d www.etedrop.cn` 一致。

## 5. Certbot

```bash
sudo apt install -y certbot python3-certbot-nginx
```

**全球机**（与 `nginx-etedrop.conf.example` 中主机名一致）：

```bash
sudo certbot certonly --webroot -w /var/www/html -d etedrop.com -d www.etedrop.com
sudo certbot certonly --webroot -w /var/www/html -d api.etedrop.com
```

**国内机**（与 `nginx-etedrop-cn.conf.example` 默认一致）：

```bash
sudo certbot certonly --webroot -w /var/www/html -d api.etedrop.cn
sudo certbot certonly --webroot -w /var/www/html -d etedrop.cn -d www.etedrop.cn
# 通配符 *.etedrop.cn 多为 DNS-01，示例见 nginx 示例文件底部注释
```

```bash
sudo certbot certificates
systemctl list-timers | grep certbot
sudo certbot renew --dry-run
```

`ssl_certificate` 路径须与 `certbot certificates` 一致。**国内**常见：`/etc/letsencrypt/live/etedrop.cn/`、`/etc/letsencrypt/live/api.etedrop.cn/`。**不要**把海外机的 `etedrop.com` 证书路径照抄到国内机。
