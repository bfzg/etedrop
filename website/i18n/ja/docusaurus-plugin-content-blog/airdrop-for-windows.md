AirDrop は Apple エコシステム内では便利 — iPhone から Windows PC へ、Android から Mac へ、というニーズには届きません。

EteDrop — 直伝設計 — が AirDrop 的な体験を Windows 等に。ケーブルなし、クラウドアップロードなし、受信側インストール不要。リンクを開き、プレビューし、DL。

## 選択肢 1：クラウド（Drive、Dropbox 等）

アップロード → リンク → DL。**動く**が、二段の旅と第三者サーバー上のデータ。**向く：** 継続的な共同編集。

## 選択肢 2：Microsoft 標準（Phone Link、Nearby Sharing）

Windows 10/11 内蔵。**限界：** 全ファイルタイプ非対応、Windows 間のみ、iPhone→PC 非対応、プレビューなし。

## 選択肢 3：サードパーティアプリ

両端末にインストール。**限界：** 両者アプリ必須、広告・アカウント、多くは結局サーバー経由。

## 選択肢 4：EteDrop — ブラウザ P2P

任意のブラウザで開き、ファイル選択、リンク送信。受信者はリンクでプレビュー後 DL。WebRTC P2P、同一 LAN では LAN モードで AirDrop に近い速度。

## iPhone から Windows へ（EteDrop）

1. iPhone（Safari）と Windows PC（Chrome / Edge / Firefox）で EteDrop を開く
2. 送信側でファイル選択
3. リンク + 受取コードを共有
4. 受信者がリンクを開き、コード入力、プレビュー、DL

## LAN モード

同一 Wi-Fi で自動。設定不要。

## 公網越え

AirDrop はネットワーク境界で止まる。EteDrop は WebRTC NAT 越えで P2P 継続 — 依然クラウド中継なし。
