# よくある質問

:::info

以下はトップページの「よくある質問」セクションから抽出した質問タイトルです。ドキュメントで一元管理しやすいようにしています。  
各 **A:** の下に詳細説明を追記・編集してください。

:::

## 1. 中央集権的なストレージに依存していますか？

**A:** コア転送は可能な限りエンドツーエンドの直接接続を使用し、サーバーは主にオンライン管理とシグナリングを担当します。

---

## 2. 公衆ネットワーク環境でも使えますか？

**A:** はい。ユーザーの約 80% のネットワーク環境で P2P 転送が利用可能です。利用できない場合はスクリーンショットを添えてご連絡ください。

---

## 3. オンラインプレビューに対応しているファイル形式は？

**A:** 受信側の **Web 共有ページ** では、次の形式をオンラインでプレビューできます（クライアントのインストール不要）。

- **動画**：標準 **MP4**（受信しながら再生可能。ブラウザとコーデックに依存）。
- **画像**：JPG、PNG、GIF、BMP、WebP、ICO、SVG など。
- **PDF**：受信完了後に**新しいタブ**で開いて閲覧可能。
- **音声**：MP3、WAV、OGG、M4A、AAC、FLAC、OPUS など（ページ内プレーヤーで再生）。
- **テキスト・コード**：TXT、Markdown、LOG、JSON/XML/YAML、CSV、一般的なソースコード拡張子など。**大容量ファイル** はページ内で全文表示できない場合があるため、必要に応じてダウンロードして確認してください（テキストプレビューにはサイズ上限があります）。

**非対応形式**（ダウンロードしてローカルソフトで開いてください）：Word / Excel / PPT、圧縮ファイル、インストーラーなど。

---

## 4. プレビュー不可・動画再生異常のときは？

**A:**

- **動画**：ブラウザでデコード可能な **MP4** が必要です。コーデック非対応と表示される場合は、ダウンロードしてローカル再生してください。**デスクトップ Safari** などではインライン動画プレビューに制限がある場合があるため、Chrome を試すかダウンロード再生を推奨します。
- **WeChat 内で開いた場合**：内蔵ブラウザの制約により、**動画プレビュー** には **MSE** などの対応が必要なことがあります。プレビューできない場合は、同じ共有リンクをシステムブラウザ（Chrome など）で開いてください。
- **画像 / PDF**：受信進捗が完了してから、案内に従って**新しいタブ**で開いてください。
- 改善しない場合は、端末機種・ブラウザ・ファイル名が分かる**スクリーンショット**を **yuanzhou_cn@qq.com** までお送りください。

---

## 5. 問題の報告方法は？

**A:** スクリーンショットと問題の説明を添えて、yuanzhou_cn@qq.com までメールしてください。
