# 모바일과 데스크톱 차이

| 비교 항목 | 모바일 | 데스크톱 |
| --- | --- | --- |
| 장시간 접근 가능성 | 장시간 화면 꺼짐 후 접근이 불가할 수 있음 | 절전 모드에 들어가지 않으면 계속 접근 가능 |
| 실시간 비디오 푸시 | 현재 미지원 | 다양한 형식의 비디오 푸시 지원 |
| 실시간 미리보기 | 미지원 | 지원 |
| 파일 관리 | 불편함 | 편리함 |
| 유지보수 우선순위 | 업그레이드 비우선 대상 | 업그레이드 및 유지보수 우선 대상 |

## 결론

현재 단계에서는 데스크톱 사용 및 유지보수를 우선하고, 모바일은 기본 사용 가능 수준을 중심으로 운영합니다.
