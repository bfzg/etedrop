AirDrop은 Apple 생태계 안에서는 훌륭 — iPhone에서 Windows PC로, Android에서 Mac으로 보낼 때는 AirDrop이 닿지 않습니다.

EteDrop — 직접 전송 설계 — 는 AirDrop式 경험을 Windows 등에. 케이블 없음, 클라우드 업로드 없음, 수신 측 앱 불필요. 링크 열기, 미리보기, 다운로드.

## 선택지 1: 클라우드(Drive, Dropbox 등)

업로드 → 링크 → 다운로드. **동작**하지만 2구간·타인 서버. **적합:** 지속 협업.

## 선택지 2: Microsoft 내장(Phone Link, Nearby Sharing)

Windows 10/11. **한계:** 모든 파일 형식 비호환, Windows 간만, iPhone→PC 불가, 미리보기 없음.

## 선택지 3: 서드파티 앱(Send Anywhere, SHAREit 등)

양쪽 설치. **한계:** 양쪽 앱, 광고, 계정; 대부분 여전히 자사 서버 경유.

## 선택지 4: EteDrop — 브라우저 P2P

열고, 파일 선택, 링크 전송. 수신: 링크에서 미리보기 후 저장. WebRTC P2P; 같은 LAN에서 LAN 모드로 AirDrop에 가까운 속도.

## iPhone → Windows (EteDrop)

1. iPhone(Safari)과 PC(Chrome/Edge/Firefox)에서 EteDrop
2. 파일 선택
3. 링크 + 픽업 코드 공유
4. 수신: 링크, 코드, 미리보기, 저장

## LAN 모드

같은 Wi-Fi에서 자동, 설정 없음.

## Wi-Fi 너머

AirDrop은 네트워크 경계에서 멈춤; EteDrop은 공인망 모드로 NAT traversal — 여전히 P2P, 클라우드 중계 없음.
