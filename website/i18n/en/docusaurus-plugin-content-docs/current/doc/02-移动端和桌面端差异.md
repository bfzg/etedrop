# Mobile vs Desktop Differences

| Item | Mobile | Desktop |
| --- | --- | --- |
| Long-term accessibility | May become inaccessible after long screen-off periods | Remains accessible as long as the device does not sleep |
| Real-time video push | Real-time video push is not supported yet | Supports video push in multiple formats |
| Real-time preview | Real-time preview is not supported | Real-time preview is supported |
| File management | Inconvenient | Convenient |
| Maintenance priority | Not a priority for upgrades | Priority for upgrades and maintenance |

## Conclusion

At this stage, desktop should be prioritized for use and maintenance; mobile focuses on basic availability.
