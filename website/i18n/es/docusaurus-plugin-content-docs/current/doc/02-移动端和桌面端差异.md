# Diferencias entre móvil y escritorio

| Elemento | Móvil | Escritorio |
| --- | --- | --- |
| Accesibilidad a largo plazo | Puede quedar inaccesible tras mucho tiempo con la pantalla apagada | Permanece accesible mientras el equipo no entre en suspensión |
| Envío de video en tiempo real | Aún no es compatible | Compatible con envío de video en múltiples formatos |
| Vista previa en tiempo real | No compatible | Compatible |
| Gestión de archivos | Poco práctica | Práctica |
| Prioridad de mantenimiento | No es prioridad de actualización | Prioridad de actualización y mantenimiento |

## Conclusión

En esta etapa, se recomienda priorizar el uso y mantenimiento de escritorio; móvil se centra en disponibilidad básica.
