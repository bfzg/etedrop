## Correo electrónico

Envía la descripción del problema y las capturas a:

**yuanzhou_cn@qq.com**

:::tip Información recomendada al reportar problemas

- Sistema y versión (por ejemplo Windows 11, macOS 15, versión de Android, etc.)
- Versión de la app
- Pasos para reproducir o descripción del comportamiento anómalo
- Capturas de pantalla o grabaciones de pantalla relacionadas (si las hay)

:::
