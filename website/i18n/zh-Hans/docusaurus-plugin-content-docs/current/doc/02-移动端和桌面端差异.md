# 移动端和桌面端差异

| 对比项 | 移动端 | 桌面端 |
| --- | --- | --- |
| 长时间可访问性 | 长期息屏后可能无法访问 | 不睡眠可持续访问 |
| 视频实时推送 | 暂不支持视频实时推送 | 支持多种格式的视频推送 |
| 实时预览 | 不支持实时预览 | 支持实时预览 |
| 文件管理 | 不方便 | 方便 |
| 维护优先级 | 非优先升级方向 | 优先升级与维护 |

## 结论

当前阶段建议优先使用并维护桌面端；移动端以基础可用为主。
