# 常见问题

## 1. 是否依赖中心化存储？

**答：** 核心传输尽量走端到端直连；服务端主要负责在线管理与信令

## 2. 公网环境能用吗？

**答：** 支持的，80% 的用户网络环境支持 p2p 传输。如不支持请截图联系我们

---

## 3. 支持哪些文件类型在线预览？

**答：** 接收方在**网页分享页**中，可对以下类型做在线预览（无需安装客户端）：

- **视频**：标准 **MP4**（支持边收边看 / 流式播放，具体依赖浏览器与视频编码）。
- **图片**：如 JPG、PNG、GIF、BMP、WebP、ICO、SVG 等。
- **PDF**：接收完成后可在**新标签页**中打开查看。
- **音频**：如 MP3、WAV、OGG、M4A、AAC、FLAC、OPUS 等，使用页内播放器。
- **文本与代码**：如 TXT、Markdown、LOG、JSON/XML/YAML、CSV，以及常见源代码扩展名等；**体积过大**时可能无法在页内展示全文，请先下载后查看（应用内对文本预览有大小上限）。

**不支持的类型**（请下载后用本机软件打开）：Word/Excel/PPT、压缩包、安装包等。

---

## 4. 预览不可用或视频播放异常怎么办？

**答：**

- **视频**：需为浏览器可解码的 **MP4**；若提示编码不支持，请下载后用本地播放器。**桌面 Safari** 等环境对内联视频预览可能有限制，可优先尝试 Chrome，或下载观看。
- **微信内打开**：受内置浏览器能力影响，**视频预览**可能需 **MSE** 等支持；若无法预览，请用系统浏览器（如 Chrome）打开同一分享链接。
- **图片 / PDF**：需在接收进度完成后，按页面提示在**新标签页**打开。
- 若仍异常，请**截图**并说明机型、浏览器与文件名，邮件 **yuanzhou_cn@qq.com**。
