AirDrop 很好用 — 若你完全活在 Apple 生态里。一旦要从 iPhone 发到 Windows PC，或从 Android 到 Mac，AirDrop 就无能为力。

EteDrop — 为直连而生 — 把 AirDrop 式体验带到 Windows。无线缆、无云端上传、接收端零安装。打开链接、预览、下载。

以下是在 Windows 上实现 AirDrop 式分享的选项及对比。

## 方案 1：云服务（Google Drive、Dropbox、OneDrive）

上传到云端，分享链接，对方下载。

**可行。** 但文件在别人服务器上，且上传 + 下载两趟。适合协作，单文件往往过重。

**适合：** 需长期保存、多人协作的文件。

## 方案 2：微软内置（手机连接、就近共享）

Windows 10/11 有手机连接（Android）与就近共享（Windows 互传）。免费内置。

**局限：** 手机连接并非全文件类型；就近共享仅 Windows；都不支持 iPhone→PC；都无预览。

**适合：** 已配置手机连接的 Android→PC 快传。

## 方案 3：第三方应用（Send Anywhere、SHAREit 等）

两端装应用，用账号或码发送。

**可行。** 但双方都要装，有的有广告、要账号，多数仍经自家服务器。

**适合：** 已习惯这些应用、不介意额外开销的用户。

## 方案 4：EteDrop — 浏览器 P2P

任意浏览器打开 EteDrop，选文件、发链接。收件人打开链接、预览、下载。

接收端无需安装。无云端上传。WebRTC P2P 设备到设备。同网 LAN 模式速度可比 AirDrop；跨网仍直连，无服务器中转。

**适合：** 跨平台、要速度与隐私、收件人零摩擦的场景。

## 用 EteDrop 从 iPhone 传到 Windows

1. **打开 EteDrop** — iPhone（Safari）与 Windows PC（Chrome、Edge、Firefox）
2. **选择文件**
3. **分享链接** — 短信、邮件、Slack 等，收件人还有取件码
4. **预览并下载** — 打开链接、输入码、预览后保存

无需线缆、无云端、接收端无需装应用。

## LAN 模式：同网 AirDrop 级速度

同一 Wi-Fi 时 LAN 模式自动启用，设备间直连，速度接近网络硬件上限。无需配置。

## 跨网：突破 Wi-Fi 边界

AirDrop 止于网络边界。EteDrop 不会。

居家办公？客户在其他办公室？公网模式用 WebRTC NAT 穿透跨网连接 — 仍 P2P、仍直连、仍无云端中转。

P2P 需双方在线 — 无异步。需先发后下时，云端可能更合适。

## 体验 + 效率

**体验：** 下载前预览，确认文档、图片、视频无误再占存储。

**效率：** LAN 自动检测同网，公网扩展覆盖而不加云端中继。
