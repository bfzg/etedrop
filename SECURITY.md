# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for vulnerabilities that may expose user data,
deployment credentials, signing keys, or service availability.

Report security issues by email:

- yuanzhou_cn@qq.com

Please include:

- affected component or platform;
- steps to reproduce;
- expected impact;
- relevant logs, screenshots, or proof-of-concept details.

The maintainer will review reports as time permits and coordinate disclosure for
confirmed issues.

## Sensitive Files

Do not commit production credentials, signing keys, certificates, private
deployment files, `.env` files, `key.properties`, Android keystores, Apple
certificates, Firebase configuration files, or Google service credentials.
